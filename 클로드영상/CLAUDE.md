# 클로드영상 폴더 규칙

이 폴더는 영상 제작 작업 공간. 배경음악은 상위 폴더의 공용 라이브러리 `../bgm/`에서 사용.

## 장면별 배경음악 선택 기준

| 장면 | 추천 장르 | 경로 |
|---|---|---|
| 오프닝 훅 (0~5초) | 웅장한 시네마틱 또는 신나는 팝 | `../bgm/03_웅장한시네마틱/`, `../bgm/01_신나는팝/` |
| 본문 설명·내레이션 | 잔잔한 로파이 | `../bgm/02_잔잔한로파이/` |
| 제품·매물 소개, 빠른 컷 | 신나는 팝 | `../bgm/01_신나는팝/` |
| 성과·결과 공개, 엔딩 CTA | 웅장한 시네마틱 | `../bgm/03_웅장한시네마틱/` |

## 작업 규칙

- 영상 스크립트·편집 계획 작성 시 장면마다 사용할 BGM 파일명을 함께 표기
- 음원 파일은 이 폴더로 복사하지 않고 `../bgm/` 경로를 그대로 참조 (중복 저장 방지)
- 라이브러리에 맞는 곡이 없으면 같은 AI 음악 도구로 새로 생성해 `../bgm/`에 추가
